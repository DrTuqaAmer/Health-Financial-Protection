# Healthcare Coverage and Financial Protection
A data analysis project comparing out-of-pocket (OOP) healthcare expenditure in Iraq and seven Middle Eastern countries from 2003 to 2023.
## Tools
• Excel and Power Query — Data cleaning
• SQLite — Data analysis
• Power BI and DAX — Data visualization and KPIs
## Data Source
World Bank – World Development Indicators
Indicator: SH.XPD.OOPC.CH.ZS
https://data.worldbank.org/indicator/SH.XPD.OOPC.CH.ZS
Key Findings (2023)
• Iraq OOP expenditure: 53.98%
• Seven-country average: 19.88%
• Difference: 34.10 percentage points
